# Get names of column variable of fmt columns

Get names of column variable of fmt columns

## Usage

``` r
# Default S3 method
get_col_var(x, ...)
```

## Arguments

- x:

  The object to test, to get a field in, or to modify.

- ...:

  Used in methods to add arguments in the future.

## Value

A single character with the col_var attribute.
