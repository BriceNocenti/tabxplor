# Test function to detect cells in reference rows

Test function to detect cells in reference rows

## Usage

``` r
# Default S3 method
is_refrow(x, ...)
```

## Arguments

- x:

  The object to test, to get a field in, or to modify.

- ...:

  Used in methods to add arguments in the future.

## Value

A logical vector with FALSE, the length of x.
