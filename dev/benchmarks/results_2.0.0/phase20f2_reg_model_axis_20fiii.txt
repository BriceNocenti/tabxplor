ceiling = (whole - sum units) + max unit, i.e. a perfect pool with a unit per core.

NOTE `sum units` is an OVER-estimate of the loop's own content: each unit built alone re-runs
the argument boundary, which the real call runs once. So `ceiling` is conservative -- a real
pool cannot beat it, and may fall short of it.
