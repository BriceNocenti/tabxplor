Phase 22b-xv-1 -- what the cascade costs
=======================================
gss_cat, n = 11 337 (tvhours non-missing, race droplevels), outcome `married`,
predictors race + rincome + relig + age. Min of 5 elapsed seconds per cell, one
full tab_reg() build each, OMP_NUM_THREADS=1. "old" is a `git archive HEAD`
build of the package before this phase.

A. NOTHING GOT SLOWER. The same estimand, asked for in each API's own words:

  spelling                                      old      new
  ------------------------------------------------------------------
  the default call (odds ratio, coefficient)   0.523    0.495
  the marginal risk difference                 0.542    0.502
  the modified Poisson's risk ratio            0.834    0.816   (`measure` -> `link`)

  Every route runs the same code it ran before, so the differences above are
  noise (+/- 5 %, both directions). The engines were GENERALISED, not extended:
  reg_gcomp_maker()'s three arms became one link table, and the identity arm
  keeps its exact arithmetic so no AME moves by an ulp.

B. WHAT MOVED IS WHICH ROUTE A SPELLING TAKES. Two spellings changed meaning
   with the cascade -- `measure` no longer refits, it reports:

  spelling                     old route             new route            old      new
  ---------------------------------------------------------------------------------------
  measure = "ratio"            an `rr` REFIT         a sweep on the logit 0.842    0.867
  measure = "difference"       an `rd` REFIT         a sweep on the logit 0.817    0.509

   So `measure = "difference"` got 38 % CHEAPER (an identity-link sweep costs
   less than an identity-link binomial refit with its convergence fallback), and
   `measure = "ratio"` costs what its refit did.

C. THE COST OF A ROUTE, for reference. A prediction route pays one
   counterfactual sweep per predictor level plus an analytic delta-method
   jacobian; a coefficient route pays a tidy(); a non-default `link` pays a
   second fit through svyglm:

  coefficient, the family's own link           0.495
  marginal, additive (a sweep)                 0.502    (+ 1 %)
  marginal, ratio (a log-scale sweep)          0.867    (+75 %)
  conditional, link = "ratio" (a refit)        0.816    (+65 %)

   The sweep's cost scales with n x levels; at n = 4 000 the same marginal
   ratio is 0.38 s against 0.25 s for the coefficient route.
