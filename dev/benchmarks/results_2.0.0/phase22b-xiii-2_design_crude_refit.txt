Phase 22b-xiii-2 (B1 / G5) -- the crude column refit at the `design` rung
========================================================================

WHAT COSTS: at the `design` rung every FACTOR predictor's crude column now comes from a univariable
svyglm through reg_empirical_fit(), where a closed form used to serve it. The numeric predictors were
already refit, so the delta is |factor_preds| extra fits per crude block. Nothing changes at the `n`
or `weights` rungs, where the closed form's independence assumption is true.

Measured 2026-08-20, WSL2 / ext4, OMP_NUM_THREADS=1, setDTthreads(1).
n = 20 000, 200 PSUs in 4 strata, 3 factor predictors (3/4/3 levels) + 1 numeric,
binomial outcome, empirical = "column", stats = FALSE. Min of 3 runs, milliseconds.

  table                                    design    weights (no refit)    delta
  -------------------------------------------------------------------------------
  effect = "coefficient"                     554            423            +131
  effect = "marginal"  (gcomp sweep)         857            682            +175

The `weights` column is the same table built one rung down, i.e. the same work WITHOUT the refit, so
the delta is the refit itself (plus, on the marginal row, one g-computation sweep per newly fitted
predictor). ~30 % of the build, on a path only a real survey design reaches, in exchange for an
interval that IS the univariable design-based fit rather than a plug-in measured 28 % narrow to 2.2x
wide (dev/reg_math_review_edge_cases.md S5.2).
