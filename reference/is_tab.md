# Is this a tabxplor table?

`TRUE` for a table built by
[`tab`](https://bricenocenti.github.io/tabxplor/reference/tab.md),
[`tab_reg`](https://bricenocenti.github.io/tabxplor/reference/tab_reg.md)
or any of their variants — i.e. for a `tabxplor_tab` (a
`tabxplor_grouped_tab` with `tab_vars`).
[`tab_structure`](https://bricenocenti.github.io/tabxplor/reference/tab_structure.md)
answers the fuller question: what structure is it, and what can be done
with it.

## Usage

``` r
is_tab(x)
```

## Arguments

- x:

  An object to test.

## Value

A single logical.
