# Printing method for a list of tabxplor tables

Printing method for a list of tabxplor tables

## Usage

``` r
# S3 method for class 'tabxplor_tabs'
print(x, ...)
```

## Arguments

- x:

  A `tabxplor_tabs` object (the list returned by
  [`tab`](https://bricenocenti.github.io/tabxplor/reference/tab.md) /
  [`tab`](https://bricenocenti.github.io/tabxplor/reference/tab.md) with
  `output_list = TRUE` for a multi-table result).

- ...:

  Passed to the per-table print method.

## Value

`x`, invisibly.
