# Printing method for a markdown table

Printing method for a markdown table

## Usage

``` r
# S3 method for class 'tabxplor_md'
print(x, ...)
```

## Arguments

- x:

  A `tabxplor_md`, as returned by
  [`tab_md`](https://bricenocenti.github.io/tabxplor/reference/tab_md.md).

- ...:

  Unused.

## Value

`x`, invisibly.
