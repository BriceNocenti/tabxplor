# A General Social Survey extract, formatted for cross-tables

[`forcats::gss_cat`](https://forcats.tidyverse.org/reference/gss_cat.html)
with levels merged into readable groups, and each variable's first level
chosen as the reference the colors and the models compare everything
else to. The data set most examples and vignettes are built on.

## Usage

``` r
gss_cat_data_formatting()
```

## Value

A tibble of 21483 rows: the US General Social Survey, 2000-2014.
