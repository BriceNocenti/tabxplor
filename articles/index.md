# Articles

### Start here

The introduction builds a first coloured table; *Reading a regression*
walks one analysis from that table to a finished sentence about a
regression.

- [Introduction to tabxplor: crosstables with
  tab()](https://bricenocenti.github.io/tabxplor/articles/tabxplor.md):

  Build a first coloured cross-table, read its colours and its legend,
  then choose what a cell shows and how it exports.

- [Reading a regression model without losing sight of the observed
  data](https://bricenocenti.github.io/tabxplor/articles/tabxplor-reading-a-regression.md):

  One analysis walked from a first cross-table to a finished sentence —
  what a model adds, what it takes away, and how to say it without
  losing the percentages.

### Going further

Look up what a regression table can be asked, what a weighted or survey
file changes, and how to write your own pipelines around the `fmt` cell.

- [Regression models with tab_reg():
  reference](https://bricenocenti.github.io/tabxplor/articles/tabxplor-reg.md):

  The reference for tab_reg() — the four estimand arguments, one part
  per kind of outcome, reading what adjustment did, and checking the
  model.

- [Weighted and survey
  data](https://bricenocenti.github.io/tabxplor/articles/tabxplor-weights.md):

  Weights, complex survey designs, and the three levels of margin of
  error — which one your file deserves, on both producers.

- [Programming with
  tabxplor](https://bricenocenti.github.io/tabxplor/articles/tabxplor-programming.md):

  Programming with the fmt cell — know what a table is, reach any field
  or attribute, and write your own pipelines.
